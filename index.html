pdfsum

Sube un PDF y obtén un resumen con sus oraciones más relevantes, generado aquí mismo, en tu navegador. El archivo nunca sale de tu computadora.

5

El PDF se procesa por completo en tu navegador con pdf.js: no se sube a ningún servidor. El algoritmo es extractivo (selecciona las oraciones más relevantes del texto original por frecuencia de palabras, cubriendo todo el documento de principio a fin) y funciona sin conexión a internet una vez cargada la página. PDFs escaneados sin capa de texto no tienen contenido extraíble.

En este modo, el texto extraído del PDF se envía directo desde tu navegador a la API de Anthropic usando tu propia clave — no pasa por ningún servidor de pdfsum, y tu clave no se guarda en ningún lado (se pierde al recargar la página). El uso tiene el costo que aplique tu cuenta de Anthropic. Para documentos largos, el texto se divide en partes que se resumen por separado y luego se combinan en un solo resumen. Si tu clave no permite llamadas directas desde el navegador, esta función no funcionará.

Resumen extractivo

Línea de comandos

Resume uno o varios PDFs desde la terminal y exporta el resultado a un archivo.

03

Tarjeta de circulación (paquete Python)

Instalar
pip install -e .
Resumir
pdfsum documento.pdf --sentences 8
Como librería
from pdfsum import extract_text, summarize

texto = extract_text("documento.pdf")
print(summarize(texto, num_sentences=5))
